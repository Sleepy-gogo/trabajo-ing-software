# Capturas de la guía

Capturas reales de SERA tomadas el 30 de septiembre de 2026 con Microsoft Edge.
La vista de escritorio usa 1440 px de ancho y la móvil, 390 px. Los archivos PNG
conservan el texto de la interfaz sin redimensionar.

Las imágenes usan cuentas ficticias y operaciones de la demo local.

Las figuras se explican en [GUIA_USUARIO.md](../../GUIA_USUARIO.md). Al actualizar
la interfaz, revisar que las etiquetas, estados y acciones sigan coincidiendo con
las instrucciones y volver a capturar las pantallas afectadas.
